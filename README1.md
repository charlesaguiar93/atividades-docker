## 📂 Passo 1: Preparar o seu Fork (Apenas na primeira vez)Se você estiver em um computador novo, certifique-se de que tem o projeto copiado no seu perfil:
Acesse o repositório do professor: GitHub - UnisenaiJoinville.
No canto superior direito, clique em Fork e depois em Create fork.
Agora você terá o link do seu próprio repositório (ex: https://github.com).


## Passo 2: Clonar o Repositório no Computador
# 1-Escolha uma pasta no seu computador (Ex: Documentos ou Área de Trabalho).
# 2-Clique no espaço em branco da barra de endereços no topo dessa pasta, digite cmd e aperte Enter para abrir o terminal.# # 3-Digite o comando abaixo para baixar a sua cópia pessoal do projeto e aperte Enter:

git clone https://github.com


# 4-Entre na pasta que foi criada digitando:

cd ADS-2025-02-Desenvolvimento-Web


## 3 Passo 3: Organizar a sua Atividade
# 1-Abra a nova pasta ADS-2025-02-Desenvolvimento-Web que apareceu no seu computador.
# 2-Navegue pelas pastas da matéria correspondente (Ex: DOCKER ou NODEJS).
# 3-Entre na sua subpasta pessoal com seu nome (Ex: Charles-de-Aguiar/charles-aguiar).
# 4-Cole os arquivos da sua nova atividade dentro dessa sua pasta pessoal.

 ## Passo 4: Abrir o Terminal na Pasta Correta
 # 1-Com a sua pasta pessoal aberta (onde você acabou de colar os arquivos), clique no espaço em branco da barra de endereços no topo.
 # 2-Digite cmd e aperte Enter (ou use o Git Bash).


 ## Passo 5: Comandos Git para Salvar e Enviar
 Copie, cole e execute um comando por vez no terminal (apertando Enter após cada um):
 1. Criar uma ramificação para a nova entrega:(Dica: mude o final para identificar a tarefa, ex: envio-tarefa-2)

git checkout -b envio-nome-da-tarefa

2. Selecionar todos os novos arquivos colados:

git add .

3. Registrar o envio com uma mensagem descritiva:

git commit -m "Envio da atividade nova - Charles Aguiar"

4. Enviar os arquivos para o seu GitHub na nuvem:

git push origin envio-nome-da-tarefa
